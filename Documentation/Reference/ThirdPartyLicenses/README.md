# Dependency License Texts

This directory preserves package license and NOTICE texts at the revisions
recorded in `Package.resolved`, plus the Swift runtime license document identified
by the owning [Third-Party Notices](../../../THIRD_PARTY_NOTICES.md) inventory.

Files keep their upstream contents. BoringSSL texts use the vendored revision
recorded by the containing package. XKCP notices preserve the relevant headers.
Update the inventory and copies together when changing a dependency.
