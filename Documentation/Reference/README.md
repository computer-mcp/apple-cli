# Reference

This directory holds user guides, developer guides, safety references, and
supporting material that is useful to readers but is not current architecture
truth.

Temporary intake and analysis material is not stable reference. Promote durable
material into this directory only after it is stable enough to serve as
repository reference, and keep current architecture rules in
`Documentation/Architecture/`.
