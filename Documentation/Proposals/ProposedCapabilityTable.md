# Proposed Capability Table

Status: Proposal draft.

## Scope / Purpose

This table records proposed capabilities and high-signal Apple implementation
mechanisms that may support current or future `apple-cli` targets. A proposed
capability is not an accepted capability. Accepted capabilities remain in
`Documentation/Architecture/CapabilityList.md` and target-local
`CapabilityList.md` files.

The table is curated from local framework and system surface discovery. It is
not a raw inventory of every private framework on the system.

## Proposal Rules

- A row in this table does not add support to `apple-cli`.
- Concrete framework names are evidence for investigation, not public command
  names and not a commitment to link or call those frameworks.
- Accepted commands must still be promoted into target-local architecture and
  capability lists.
- Direct store writes remain unaccepted unless a future target-specific
  decision explicitly accepts that mechanism.
- MCP remains an adapter over the CLI contract and does not own proposed
  capability behavior.
